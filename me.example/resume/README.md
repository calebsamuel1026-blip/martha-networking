# Put your résumé PDF here

1. Save your résumé as a PDF in this folder (`me/resume/`).
2. Give it a clean name, like `First-Last-Resume.pdf`. Recipients see this file name.
3. Put the same file name in `me/profile.md` on the `resume:` line.

The send tool attaches it to every first email ("Resume attached."). Follow-ups and replies go without it unless you ask.

One PDF is enough. If you keep versions for different fields, put them all here and tell Claude which one goes with which firms.

This folder is private: `me/` is gitignored, so your résumé never ends up on GitHub.
